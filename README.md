# Couto Cell

Site da Couto Cell, assistência de celulares na Freguesia do Ó, São Paulo.

Layout adaptado da Lancell com identidade em branco, roxo e lilás.

## Desenvolvimento

`npm run dev` abre o servidor em http://localhost:3000.

`npm run check` valida o JavaScript. `npm run build` gera a pasta dist para publicação na Vercel.
